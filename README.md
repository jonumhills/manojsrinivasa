# manojsrinivasa

A small multi-page portfolio, no build step.

- `index.html` — photo, name, contact, hot/honorable projects ribbon, a
  failure-streak donut, and links to the three pages below
- `projects.html` — all five ventures, one tagline each
- `hackathons.html` — the hackathon win streak, chronological
- `books.html` — a quote and a couple of book recommendations

`styles.css` and `theme.js` are shared across all four pages.

## Deploy

Static files, no build step. To serve via GitHub Pages: repo **Settings →
Pages → Deploy from a branch → `main` / `/ (root)`**.
