# manojsrinivasa

A single-page portfolio — "how many times have i actually tried so far" —
listing ventures by how they actually went (not how they started), a
hackathon-wins streak, and a work-history timeline.

## Deploy

Static single file, no build step. To serve via GitHub Pages: repo **Settings →
Pages → Deploy from a branch → `main` / `/ (root)`**.
